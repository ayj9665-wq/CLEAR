## 1. 프로젝트 한 줄 정의
미국 살인사건 데이터(MAP, 1980–2014, 약 63만 건)를 사건 그래프로 재구성해 GNN으로 **검거 여부를 예측(예측)**하고, 그 안의 **피해자 인종·성별 격차를 측정(진단)**한 뒤, **완화기법으로 격차를 얼마나 줄일 수 있는지(처방)**를 정량화한다.

전체 흐름은 하나의 질문("무엇이 검거를 결정하는가")을 **예측 → 진단 → 처방** 세 단계로 파고드는 구조이며, 그래프(GNN)는 이 전 단계를 관통하는 예측 도구다.

> **이 문서는 착수 시점(2026-07-20)의 계획이고 그대로 남겨 둔다** — 무엇을 예측했고 무엇이 빗나갔는지가 결과의 일부이기 때문이다. 실제 진행에서 달라진 큰 항목 셋: ① **적용** 단계가 네 번째로 추가됐다(카운티 이상탐지 + 전국 웹 지도, [확장설계서](확장설계서_CLEAR.md)), ② 엣지는 "특성 유사도 top-k"가 아니라 **블로킹 + 셔플-링**으로 만들었고 유사도 랭킹은 실제로 만들어 학습한 뒤 **기각**했다(§2-8), ③ 표본이 3개 주에서 **전국 63.8만 건**으로 확장됐다. 최종 결과는 [최종보고서](최종보고서_CLEAR.md)에 있다.

## 3. 데이터 파이프라인 (아키텍처 흐름)

원천 CSV 한 장이 최종 그래프 객체가 되기까지의 흐름이다. 각 단계는 독립 스크립트로 분리해 재현성을 확보한다.

```
database.csv (638,454행)
      │
      ▼
[1] 정제(clean)  ── 누수 열 제거 · 결측 처리 · 타입 정리
      │
      ▼
[2] 표본 추출(sample) ── 주(州)/기간 기준 5만~10만 행으로 축소
      │
      ▼
[3] 특성 공학(feature engineering) ── 노드 특성 인코딩
      │
      ▼
[4] 그래프 구성(build graph) ── 엣지 정의 · 인접행렬 생성
      │
      ▼
[5] 학습/검증/평가 분할(split) ── 시간 기반 분할(과거→미래)
      │
      ▼
PyG Data 객체 (x, edge_index, y, sensitive)
```

**[1] 정제 — 반드시 처리할 것**
- 타깃 누수 열 제거(검증 완료): `Perpetrator Sex/Age/Race/Ethnicity`, `Perpetrator Count`, `Relationship`. 미해결 사건에서 90~99% Unknown이라 사실상 정답 누설.
- 저정보 열 제거: `Crime Type`(98.6% 단일값).
- 식별자 분리: `Record ID`는 인덱스로만, 학습 특성에서 제외.
- 타깃 인코딩: `Crime Solved` → Yes=1(검거), No=0(미해결).

**[2] 표본 추출 — 논문 기준(Campedelli 2022)**
- 논문은 전국 모델에 **전체 데이터를 그대로** 사용(다운샘플링 없음). 대신 **주(州)별로 데이터를 분할**해 지역 서브셋으로 분석(예: California N≈12만, Texas N≈7.7만, Michigan N≈3.5만).
- 본 프로젝트: GNN 학습 부담을 고려해 **주(州) 단위로 잘라** 5만~10만 노드 그래프를 구성(논문의 주별 분할 전략과 정합). 축소 시에도 인종·성별 분포와 검거/미해결 비율(70:30)이 유지되는지 확인(층화 표집).

**[3] 특성 공학 (노드 특성 x) — 논문 기준: 전면 One-Hot**
- 논문은 **모든 변수를 One-Hot 인코딩**. 본 프로젝트도 이 기준을 따른다.
- 범주형(Victim Sex, Victim Race, Victim Ethnicity, Weapon, Month, Agency Type): One-Hot.
- **피해자 나이: 연속값이 아니라 5년 단위 구간으로 구간화(binning) 후 One-Hot** (논문 방식). 결측·이상치(예: Age 998/999=unknown 코드)는 별도 범주로.
- 연도: 논문처럼 Decade(10년 단위)로 묶어 One-Hot 가능.
- Victim Count: 수치형 유지(안전한 특성). ※ Perpetrator Count는 누수라 제외.
- 지역·시기(State, City, Year, Month)는 노드 특성이자 엣지 재료로 이중 사용.

**[5] 데이터 분할 — 논문 기준: 70/30 무작위 층화 + 5-fold CV**
- 논문은 **70% 학습 / 30% 평가**로 분할하고, 하이퍼파라미터는 **5-fold 층화 교차검증**으로 튜닝.
- 분할 전 **무작위 셔플**을 명시적으로 수행 — 시간 의존 패턴·공변량 이동(covariate shift)을 피하려는 의도. (본 프로젝트도 시간 기반 대신 이 무작위 층화 분할을 채택. GNN 전이학습의 노드 무작위 마스킹과도 정합.)
- 층화 기준: 타깃(Crime Solved) 비율 유지.

## 4. 그래프 설계 (핵심 설계 결정)

이 프로젝트의 성패는 "무엇을 엣지로 볼 것인가"에 달려 있다. 사건 = 노드, 유사성 = 엣지.

**노드(Node)**
- 하나의 살인사건 = 하나의 노드.
- 노드 특성 = [3]에서 만든 피해자·사건 특성 벡터.

**엣지(Edge) — 3종 후보를 실험**
1. 지리적 근접: 같은 State 또는 같은 Agency(관할)면 연결.
2. 시간적 근접: 같은 Year·Month 창(window) 내면 연결.
3. 수법 유사: 같은 Weapon·피해자 유형이면 연결.

**엣지 폭발 방지 (중요)**
- 위 조건을 그대로 AND/OR로 걸면 노드당 수천 개 엣지가 생겨 학습 불가.
- 대안: **k-NN 그래프** — 특성 유사도 상위 k개(예: k=10)만 연결해 밀도를 통제.
- 라벨: 최종 그래프의 평균 차수(degree)·연결 성분 수를 반드시 로깅해 그래프가 너무 성기거나(고립 노드 다수) 과밀하지 않은지 점검.

## 5. 모델 아키텍처 (예측 → 진단 → 처방 흐름)

```
      PyG Data(x, edge_index, y, sensitive)
                    │
        ┌───────────┴───────────┐
        ▼                       ▼
[베이스라인]              [메인 모델]
XGBoost / LogReg          GNN (2~3 layer GraphSAGE)
(그래프 무시,             x ─▶ GraphConv ─▶ ReLU ─▶ Dropout
 노드 특성만)                 ─▶ GraphConv ─▶ 노드 임베딩 h
        │                       │
        │                       ▼
        │                 분류 헤드(MLP) ─▶ sigmoid ─▶ 검거 확률 ŷ
        └───────────┬───────────┘
                    ▼
        [진단] ŷ를 sensitive(인종·성별)로 분해
                → equalized odds / demographic parity 격차 측정
                    │
                    ▼
        [처방] 완화기법 적용
          · 전처리: reweighing
          · 후처리: equalized-odds post-processing
          · 인프로세싱: adversarial debiasing
                → 완화 전후 정확도·공정성 재측정
                    │
                    ▼
        정확도 vs 공정성 트레이드오프 곡선
```

**모델 흐름 상세**
1. **입력**: 노드 특성 행렬 `x`(N×F), 엣지 인덱스 `edge_index`(2×E), 라벨 `y`, 민감속성 `sensitive`.
2. **베이스라인**: 그래프를 무시하고 노드 특성만으로 XGBoost·로지스틱 회귀를 학습. "그래프가 실제로 도움이 되는가"를 판정할 기준선.
3. **GNN 본체**: GraphSAGE(또는 GCN) 2~3층. 각 층은 이웃 노드의 특성을 집계(aggregate)해 자기 표현을 갱신 → 사건 하나만으로는 안 보이던 "주변 사건의 맥락"을 임베딩에 반영.
4. **분류 헤드**: GNN이 만든 노드 임베딩 `h`를 MLP+sigmoid에 통과시켜 검거 확률 출력.
5. **불균형 처리**: 미해결이 소수(30%)이므로 손실에 class weight 적용, 평가는 PR-AUC·F1 중심(정확도만 보면 착시).
6. **진단·처방**: 위 확률을 민감속성으로 분해해 공정성 측정 → 완화기법 적용 → 재측정.
